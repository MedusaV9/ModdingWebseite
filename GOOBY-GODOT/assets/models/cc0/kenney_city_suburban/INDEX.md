# Kenney City Kit Suburban 2.0 — kuratierte Auswahl (CC0)

Quelle: https://kenney.nl/assets/city-kit-suburban (Direkt-ZIP, CC0).
Das Repo hat bisher NUR Kleinteile dieses Kits (Zäune/Wege/Bäume in
`assets/city/vorstadt/` + `assets/furniture/kenney-suburb/`), aber keine
einzigen Wohnhäuser. Texturen: `Textures/colormap.png` neben den GLBs.

| Modell | Gedachter Einsatzort |
| --- | --- |
| `building_type_a.glb` … `building_type_u.glb` (21 Häuser) | Vorstadt-Distrikt der Stadt: echte Wohnstraßen statt wiederholter Kulissen; Nachbarhäuser rund ums Gooby-Haus; Hintergrund für Delivery-Rush-Routen |
| `driveway_long.glb` | Einfahrten vor den Häusern (Repo hat nur `driveway-short`) |
| `fence.glb`, `fence_1x3.glb` | Gartenzaun-Lücken schließen (Repo hat 1x4/2x2/low) |
| `path_long.glb`, `path_short.glb` | Gehwege zu den Haustüren (Repo hat nur die Stein-Varianten) |
