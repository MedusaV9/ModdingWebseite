# UV map — Glitched Wanderer (`assets/eclipse/textures/entity/glitched_wanderer.png` + `_alt.png` + 2 glowmasks)

**Texture size:** 64×64 — **four files**, exactly the [Glitched Husk](glitched_husk.md)
layout: `glitched_wanderer.png` (calm frame), `glitched_wanderer_alt.png` (corruption
frame), and a `_glowmask.png` for EACH (`AutoGlowingTexture` appends `_glowmask` to
whichever albedo is active). Model:
`assets/eclipse/geo/entity/glitched_wanderer.geo.json` (GeckoLib, **12 bones / 11
cubes**). The geo file **is** the UV source of truth — and both the geo and the sheets
are GENERATED, so every change below belongs in the painter, never in the PNGs.

The Wanderer is the husk geometry **warped**: the UV islands keep their husk
coordinates (so the husk's material language paints straight onto it), but the cubes
are the wrong size for a person.

| Bone | Cube | Box W×H×D | UV | Inflate | Warp vs. husk |
|---|---|---|---|---|---|
| `body` | torso | 8×12×4 | (0,0) | 0 | — |
| `shard_torso` | detached slab | 4×7×4 | (0,16) | 0 | — |
| `glow_seam` | seam disc | 6×1×6 | (0,43) | 0 | fully emissive |
| `glow_seam` | seam sliver | 1×10×1 | (24,43) | +0.2 | fully emissive |
| `head` | skull | 8×8×8 | (24,0) | **−0.75** | deflated small |
| `head_shard` | displaced half-face | 5×4×3 | (16,16) | **−0.35** | deflated small |
| `jaw_shard` | dislocated jaw | 4×2×2 | **(32,40)** | **−0.2** | **UV re-parked** (see below) |
| `arm_right` | LONG arm | 3×**20**×3 | (32,16) | 0 | husk 16 → 20, drags past the knee |
| `arm_left` | short arm | 3×**15**×3 | (44,16) | 0 | husk 10 → 15 |
| `leg_right` / `leg_left` | legs | 4×12×4 | (0,27) / (16,27) | 0 | — |
| `fx_shroud_anchor` | — | *(no cubes)* | — | — | **NEW, MB5** — see §FX |

**Why the jaw moved:** stretching `arm_right` to 20 tall grows its box-UV strip to
y16..**39** (2·(3+3) = 12 wide × (3+20) = 23 tall from (32,16)). The husk parks the jaw
at (32,36), which now lands inside the arm strip. The Wanderer's jaw is therefore
re-parked to **(32,40)** → occupies x32..44 / y40..44, clear of the arm and inside the
64×64 canvas. `arm_left` at (44,16) spans x44..56 / y16..34 — also clear.

**Art brief:** the husk's glitch material set (`scripts/geckolib_gen/mobs/glitch_lib.py`,
via `glitched_husk.build`) painted onto the WARPED geo — so the longer arm strips are
fully textured, not stretched — then regraded **mono-yellow "wet paint"**: luminance
mapped through a rot-yellow ramp (`#181206` damp baseboard → `#5E4A18` → `#A88A32`
→ `#D6BC68` → `#F0E0A4` pale fluorescent), which is the damp-wallpaper read of the
Backrooms. The `_alt` frame's corruption pixels (those differing from the base by
> 90 in summed RGB) flare **hot pale-yellow** instead, so the datamosh burst still
reads inside a monochrome palette.

**Emissive (glowmask):** the husk masks re-tinted to the fluorescent froglight note —
pale yellow scaled by luminance (`#C8B45A` → `#FFFFA0`). The emissive glitch scars and
seam inherit it; the alt masks add wider bleed.

**Also generated by this painter:** `textures/gui/backrooms_scare.png` (256×256) — THE
jumpscare face, the Wanderer's own 8×8 head front face (UV 32,8) blown up ×32 with
hollowed eye voids, a gaping mouth, deterministic scanline displacement and a vignette.
`JumpscareOverlay` caps it at 85 % alpha.

## FX — `fx_shroud_anchor` (the published emitter locator for B2)

```
{ "name": "fx_shroud_anchor", "parent": "root", "pivot": [0, 15.36, 0] }
```

Cubeless locator: it paints nothing, costs nothing, and exists purely so B2's
`eclipse:wanderer_static_shroud` can bind to the model instead of to a world-space
offset.

- **Pivot 15.36 px is not arbitrary.** `PhotonMobFx`'s `LoopRow` currently anchors the
  shroud at `eye + (0, −0.7, 0)`, and `BackroomsEntities` gives the Wanderer
  `eyeHeight(1.66F)`. So 1.66 − 0.70 = **0.96 blocks = 15.36 model px** — the locator
  sits exactly where the emitter already sits today.
- **Parented to `root`, deliberately NOT to `body`.** The shroud is a column of haze
  around the thing; inheriting the torso's 20° forward pitch during `sprint` would tip
  the whole column over.
- **It carries no animation channel in any clip** — also deliberate. A bone-bound
  emitter therefore differs from today's world-space row by exactly the `root` bone's
  own motion and nothing else: 0 px in `idle` and during the `notice` hold, ≤ 1.35 px
  (0.084 blocks) of bob in `sprint`, plus the `glitch_blink` stutter and the `death`
  sink — which is precisely the drift a shroud *should* inherit.

## Regenerating (deterministic, byte-identical reruns)

```
python3 scripts/geckolib_gen/mobs/backrooms_wanderer.py
```

Writes the geo, the animation file, all 4 entity PNGs and the scare face. It reads
`glitched_husk.geo.json` / `glitched_husk.animation.json` as its source, so **whenever
the husk changes, re-run this painter** or the Wanderer's inherited
`attack`/`glitch_blink`/`death` clips go stale.

Final AI art may replace the PNGs byte-for-byte at the same paths/canvas size; keep
base↔alt aligned per-pixel or the renderer's corruption swap will smear.
