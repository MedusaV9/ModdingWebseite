# SoooDreamy 6.0.0 — Zusammen, überall

- Geführter, passwortverschlüsselter Umzug logischer Paar-Daten von Server A zu einem frischen Paar auf Server B.
- SHA-256-Inhaltsprüfung, Schema-Gate, 16-MB-JSON-Grenze und atomare Ablehnung manipulierter oder nicht leerer Ziele.
- Tokens werden nie importiert; der zweite Partner koppelt sich mit dem neuen Code erneut.
- Der End-to-End-Test beweist bytegleiche normalisierte logische Inhalte vor und nach Import sowie erneuter Kopplung.

Ehrliche Grenze: Große Medien-Binärdateien müssen der Server-Admin separat aus dem Datenordner kopieren. IPA unsigniert; Geräteprüfung: nein.
