# Quaternius Ultimate Crops — kuratierte Auswahl (CC0)

Quelle: https://quaternius.com/packs/ultimatecrops.html (CC0, Original nur
FBX/OBJ/Blend; hier via Blender 4.0 nach GLB konvertiert, flache Materialien,
keine Texturen). Namensschema: `<pflanze>_1..4` = Wachstumsstufen,
`<pflanze>_crop` = fertige Beet-Reihe, `_harvested` = geerntet.

| Modell | Gedachter Einsatzort |
| --- | --- |
| `carrot_1.glb` … `carrot_4.glb`, `carrot_crop.glb` | Ranch-Gemüsegarten mit sichtbarem Wachstum; Karotten sind DAS Gooby-Motiv (carrot_catch/carrot_guard-Kulissen) |
| `tomato_1.glb` … `tomato_4.glb`, `tomato_crop.glb` | Gewächshaus (`gewaechshaus.glb`) endlich mit wachsendem Inhalt; ersetzt statische `pflanze_tomate` |
| `pumpkin_2.glb`, `pumpkin_4.glb`, `pumpkin_crop.glb`, `pumpkin_harvested.glb` | Ranch-Herbstfeld; Halloween-Brücke zu kaykit-halloween |
| `wheat_2.glb`, `wheat_4.glb`, `wheat_crop.glb` | Ranch-Weizenfeld (Kulisse hinter der Koppel), Windmühlen-Umfeld |
| `corn_2.glb`, `corn_4.glb`, `corn_crop.glb` | Ranch-Maisfeld-Rand, Wochenmarkt-Ware |
| `lettuce_2.glb`, `lettuce_4.glb`, `lettuce_crop.glb` | Gemüsegarten, REHWEI-Frischetheke |
| `bush_berries_2.glb`, `bush_berries_4.glb` | Garten-/Parkränder, Sammel-Spot auf der Ranch |
| `beet_2.glb`, `beet_4.glb`, `beet_crop.glb` | Gemüsegarten-Vielfalt |
| `apple_4.glb`, `apple_crop.glb` | Obstwiese an der Ranch, Haus-Garten |
| `watermelon_crop.glb`, `watermelon_harvested.glb` | Sommer-Event, Wochenmarkt-Hingucker |
| `palm_tree_1.glb` … `palm_tree_4.glb` | Urlaubs-Ort (`urlaubs_ort.gd` ist bisher fast nur Primitives!), Flughafen-Deko |
